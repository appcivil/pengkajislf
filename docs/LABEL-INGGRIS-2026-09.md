## B. Sengaja DIBIARKAN berbahasa Inggris

| Label | Alasan |
|---|---|
| Pushover Analysis · Pushover Analysis Required | istilah baku rekayasa struktur (analisis dorong bertahap; SNI 1726 / FEMA 356) — lazim ditulis apa adanya dalam laporan teknis |
| ACH Minimum Required | singkatan baku ASHRAE: ACH = *air changes per hour*; angkanya merujuk tabel standar |
| DF Minimum Required | singkatan baku: DF = *daylight factor* |
| Daylight Factor · Noise Criteria · Air Flow Rate · AHU | kosakata profesi yang sudah baku bagi insinyur Indonesia; menerjemahkannya justru menyimpang dari rujukan SNI/ASHRAE |
| NFPA 13, SNI 1726, ASCE 41-17, ASTM C597, ISO/IEC … | nama resmi dokumen standar |
| Google Cloud (SIMBG), Excel, DOCX, PDF, IES, EPANET | nama layanan/format berkas |

## C. Belum diterjemahkan (bukan label, melainkan NILAI DATA)

Beberapa teks yang tampil di layar datang dari **nilai data**: mis. kolom "Status:"
diikuti `COMPLIANT` / `NON-COMPLIANT` / `Wheelchair Accessible`, yang dihasilkan
lapisan perhitungan. Nilai-nilai itu dipakai juga sebagai pembanding di dalam kode
(`status === 'COMPLIANT'`), jadi menerjemahkannya di lapisan tampilan saja tidak
cukup: harus disertai pemetaan nilai di seluruh aplikasi. Ini kelas pekerjaan
tersendiri dan **belum** dikerjakan — silakan beri tahu kalau ingin saya lanjutkan.

```bash
node scripts/ux-audit.mjs --verbose      # aturan E5 melaporkan label Inggris yang tersisa
node tools/daftar-label.mjs .     # daftar label dari teks di template/atribut
node tools/daftar-label-data.mjs . # daftar label yang datang dari data ({ text: '…' })
```
